# Escolha do gráfico

Comece pela pergunta que o leitor deve conseguir responder olhando o gráfico.

| Pergunta do leitor | Gráfico | Cuidados |
|---|---|---|
| "Qual é o número?" | texto grande + frase | um ou dois números, no máximo |
| "Qual é o valor exato de X?" | tabela leve | sem grade pesada; alinhe números à direita |
| "Onde estão os altos e baixos da tabela?" | mapa de calor | uma cor sequencial; legenda |
| "Como evoluiu no tempo?" | linha | eixo x com intervalos regulares; até ~5 séries, o resto em cinza |
| "Quem subiu e quem caiu entre A e B?" | inclinação (slope) | só dois pontos no tempo; rótulos nas pontas |
| "Qual categoria é maior?" | barra (horizontal se nomes longos) | base zero; ordenar por valor |
| "Quanto cada parte contribui para o total?" | barra simples ou empilhada a 100% | poucas partes; parte de interesse na base ou em cor |
| "Como chegamos de X a Y?" | cascata | cores para soma e subtração; total em cinza escuro |
| "As duas coisas andam juntas?" | dispersão | linha de referência; destaque os pontos fora do padrão |
| "Como os valores se distribuem?" | histograma ou boxplot | explique o boxplot se a audiência não for técnica |
| "Como está contra a meta?" | barra/linha + linha de meta | a meta como linha fina rotulada, não como série |

## Sinais de alerta

- **Pizza/rosca** → troque por barras horizontais ordenadas.
- **Mais de ~5 linhas coloridas** → cinza para todas, cor só para 1–2; ou pequenos múltiplos (um mini-gráfico por série, mesmo eixo).
- **Eixo duplo** → dois gráficos alinhados no eixo x, ou rótulos diretos numa das séries.
- **Barra com eixo que não começa no zero** → comece no zero ou troque por linha/pontos (que não exigem zero).
- **Rótulos inclinados** → barras horizontais.
- **Legenda longe dos dados** → rótulo direto.
- **3D, sombra, gradiente** → remova.

## Pequenos múltiplos

Quando há muitas séries e cada uma importa, um painel por série (mesma escala, mesmo eixo, lado a lado) costuma ser melhor do que uma única figura com um emaranhado de linhas.
